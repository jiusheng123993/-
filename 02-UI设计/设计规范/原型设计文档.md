## 一、设计规范

### 1.1 色彩系统

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 品牌主色 | `#4A90D9` | 主按钮、导航、强调 |
| 品牌辅色 | `#7BB3E8` | 次要按钮、hover状态 |
| 成功色 | `#52C41A` | 正常状态、完成标记 |
| 警告色 | `#FAAD14` | 关注状态、提醒 |
| 危险色 | `#F5222D` | 紧急状态、错误 |
| 背景色 | `#F5F7FA` | 页面背景 |
| 卡片背景 | `#FFFFFF` | 卡片、弹窗 |
| 文字主色 | `#1A1A1A` | 标题、正文 |
| 文字次色 | `#666666` | 辅助文字 |
| 边框色 | `#E8E8E8` | 分割线、边框 |

### 1.2 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 20px | 600 | 页面顶部标题 |
| 模块标题 | 16px | 600 | 卡片标题、模块标题 |
| 正文 | 14px | 400 | 普通文字 |
| 辅助文字 | 12px | 400 | 说明、提示 |
| 数字强调 | 24px | 700 | 关键数据展示 |

### 1.3 间距规范

| 类型 | 数值 | 用途 |
|------|------|------|
| 页面边距 | 16px | 左右边距 |
| 卡片间距 | 12px | 卡片之间 |
| 元素间距 | 8px | 内部元素 |
| 圆角 | 12px | 卡片、按钮 |
| 小圆角 | 8px | 小按钮、标签 |
