# 架构星图

“架构星图”把工程系统视为一座有轨道、有引力、有边界的城市。核心应用不是被文字解释出来的，而是通过层级、距离、线条和色块自然显现：入口层像城市外环，业务能力像稳定的中枢街区，支付与权益像高密度基础设施，平台输出像向外延伸的港口。最终作品必须是被精细推敲过的视觉系统，节点、间距、曲线和颜色都要呈现出经过长时间打磨的专业秩序。

它的空间语言强调“中心—分区—流向”。中心模块拥有最高视觉引力，外围模块按职责成簇排列，所有关系以克制的连线表达，避免装饰性堆叠。信息不是靠段落说明，而是靠模块之间的方位、尺寸、连接密度和颜色分区传达。作品应像资深架构师与高级信息设计师共同反复校准后的成果，具备严谨、安静、可追踪的工程美感。

色彩采用深色基底与少量高亮信号。蓝色表示前端体验与界面，绿色表示数据与状态，紫色表示权益与会员，橙色表示支付与订单，青色表示平台与运行外壳。文字只作为坐标标签存在，保持稀疏、清晰、准确，不能喧宾夺主。每个标签都必须像仪器刻度一样经过慎重安放，体现大师级的细节控制。

线条使用柔和但明确的路径，表现调用、依赖、数据流、平台出口和安全边界。它们不追求复杂炫技，而追求一眼能看出系统如何工作、哪里是扩展点、哪里是核心契约。最终画面应当像一张可被长期挂在团队墙上的工程星图，既能被非技术人员直观看懂，也能让后续智能体快速接手项目结构。
