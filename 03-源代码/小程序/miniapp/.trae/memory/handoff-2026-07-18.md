## 技术要点

### 新方向数据流
```
用户操作 → petStore/checkinStore/... → memory-body → Supabase
```

### 新方向页面结构
```
TabBar: 首页 | 我的宠物 | 会员 | 我的
功能页: 3秒打卡 | 食物查询 | 症状初筛 | 疫苗日历 | 健康趋势 | 宠物档案
```

### AI策略
- MVP: 纯规则引擎（0成本，无LLM调用）
- PetSafetyHandler: 有毒食物过滤 + 医疗免责声明
- 症状初筛: 规则引擎 + 严重度评估 + 就医建议
