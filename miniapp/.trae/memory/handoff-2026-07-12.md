## 技术要点

### 数据流
```
用户操作 → scheduleStore → MiniProgramMemoryBodyStore → 本地存储
```

### 组件关系
```
CalendarPage
├── MonthlySummary (月度统计)
├── EmotionCalendar (日历视图)
└── DayDetailModal (日期详情弹窗)
```

### 风险等级计算
- 强度 >= 8: critical (红色)
- 强度 >= 6: high (橙色)
- 强度 >= 4: medium (黄色)
- 强度 < 4: low (绿色)
