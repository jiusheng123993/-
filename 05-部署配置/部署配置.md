## 六、部署步骤

```bash
# 1. 更新代码（git pull 或上传部署包）
# 2. 安装依赖
cd /opt/xinghuanhai/server && npm install
# 3. 执行数据库迁移（幂等；022_knowledge_graph.sql 自动建 knowledge_graphs / knowledge_feedback 表）
npm run migrate
# 4. 重启
pm2 restart xinghuanhai-server
# 5. 验证
curl https://api.xinghuanhai.com/api/health
curl https://api.xinghuanhai.com/api/knowledge/latest   # 图谱下发（空表自动用种子播种）
# 6. 管理后台（浏览器）: https://api.xinghuanhai.com/admin （输入 ADMIN_TOKEN）
```

> ⚠️ 迁移遇"must be owner of table"：用 `sudo -u postgres psql -d <库名>` 执行，并 `ALTER TABLE ... OWNER TO xinghuanhai`。
> ⚠️ 知识图谱上线前必须配 `ADMIN_TOKEN`（管理接口 fail-closed）；种子 `server/src/data/medicalGraphSeed.json` 是前端图谱快照，**改 `medicalGraph.ts` 需同步重新导出**（DB 播种后服务端以 DB 为权威）。
