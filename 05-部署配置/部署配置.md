## 六、部署步骤

```bash
# 1. 更新代码（git pull 或上传部署包）
# 2. 安装依赖
cd /opt/xinghuanhai/server && npm install
# 3. 执行数据库迁移（幂等）
npm run migrate
# 4. 重启
pm2 restart xinghuanhai-server
# 5. 验证
curl https://api.xinghuanhai.com/api/health
```

> ⚠️ 迁移遇"must be owner of table"：用 `sudo -u postgres psql -d <库名>` 执行，并 `ALTER TABLE ... OWNER TO xinghuanhai`。
