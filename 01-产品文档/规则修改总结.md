# 全局规则修改总结：codebase-memory-mcp 优先

## 修改概述

将 `codebase-memory-mcp` 设为代码分析的首选工具，`CodeGraph` 作为降级备选。共修改 2 个全局规则文件。

---

## 修改文件清单

| 序号 | 原文件 | 修改后文件 | 修改内容 |
|------|--------|-----------|---------|
| 1 | `rule-01-session-start.md` | `rule-01-session-start-updated.md` | 会话开始流程中加入 codebase-memory-mcp 状态检查 |
| 2 | `rule-03-codegraph.md` | `rule-03-codegraph-updated.md` | 将 CodeGraph 替换为 codebase-memory-mcp 优先，CodeGraph 降级 |

---

## 核心修改点

### 1. 工具优先级重新定义

**修改前：**
- CodeGraph 为"唯一前置权威工具"
- 所有代码分析任务强制使用 CodeGraph

**修改后：**
- **codebase-memory-mcp 为首选前置权威工具**
- CodeGraph 作为降级备选工具
- 明确降级流程和条件

### 2. 任务类型强制映射更新

| 任务类型 | 修改前（CodeGraph） | 修改后（codebase-memory-mcp） | 降级备选 |
|---------|-------------------|---------------------------|---------|
| 代码搜索 | `codegraph_search` | `search_graph` / `search_code` | `codegraph_search` |
| 查看源码 | `codegraph_node` | `get_code_snippet` | `codegraph_node` |
| 上游调用 | `codegraph_callers` | `trace_path` (inbound) | `codegraph_callers` |
| 下游依赖 | `codegraph_callees` | `trace_path` (outbound) | `codegraph_callees` |
| 调用链路 | `codegraph_trace` | `trace_path` (both) | `codegraph_trace` |
| 模块上下文 | `codegraph_context` | `get_architecture` | `codegraph_context` |
| 关联分析 | `codegraph_explore` | `query_graph` | `codegraph_explore` |
| 项目结构 | `codegraph_files` | `get_architecture` | `codegraph_files` |
| 影响分析 | `codegraph_impact` | `detect_changes` | `codegraph_impact` |
| 索引管理 | `codegraph_status/init/sync` | `index_status` / `index_repository` | `codegraph_status/init/sync` |

### 3. 会话开始流程更新

**修改前：**
```
步骤 5：CodeGraph 分析项目结构（codegraph_status → codegraph_files → codegraph_context）
```

**修改后：**
```
步骤 5：检查代码分析工具状态（codebase-memory-mcp 优先）
- 调用 list_projects 或 index_status 检查 codebase-memory-mcp 可用性
- 若可用，记录状态为 "codebase-memory-mcp 就绪"
- 若不可用，降级检查 CodeGraph 状态（codegraph_status）
- 若均不可用，记录降级原因，标注精度风险
```

### 4. 代码修改标准前置流程更新

**修改前（CodeGraph 流程）：**
```
codegraph_status → codegraph_search → codegraph_node → codegraph_callers → codegraph_callees → codegraph_impact
```

**修改后（codebase-memory-mcp 优先流程）：**
```
index_status → search_graph → get_code_snippet → trace_path → trace_path → detect_changes
```

**降级流程（codebase-memory-mcp 不可用时）：**
```
codegraph_status → codegraph_search → codegraph_node → codegraph_callers → codegraph_callees → codegraph_impact
```

## 使用方式

### 1. 替换全局规则文件

将以下两个文件复制到全局规则目录，替换原有文件：

```
目标：c:\Users\zhang\.trae-cn\user_rules\rule-03-codegraph.md
```

### 2. 重启 Trae

替换完成后，**重启 Trae** 使新规则生效。

### 3. 验证规则生效

重启后，Agent 在会话开始时会：
1. 优先检查 `codebase-memory-mcp` 状态
2. 若可用，使用 `codebase-memory-mcp` 进行代码分析
3. 若不可用，自动降级使用 `CodeGraph`

---

## 注意事项

1. **降级机制**：当 `codebase-memory-mcp` 不可用时，会自动降级使用 `CodeGraph`，无需手动干预
2. **精度风险**：降级使用时，Agent 会标注降级原因和精度风险
3. **工具恢复**：`codebase-memory-mcp` 恢复后，Agent 会立即回归标准流程
4. **索引管理**：两个工具各自维护独立索引，需要分别初始化和同步
