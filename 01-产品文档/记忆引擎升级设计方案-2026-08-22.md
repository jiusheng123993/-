## 二、记忆分层（解决"千条记忆杂乱 + 规模化"）

```
所有记忆
├── 流水层（日常低价值：吃了/玩了/睡了）
│     └── 自动衰减 → dormant → expired（现有机制强化）
└── 核心层（高价值，长期保留）
      ├── 里程碑（到家/生日/疫苗/技能）
      ├── 健康事件（生病/恢复/就医/异常）
      ├── 用户标注（"这是最珍贵的"/"选入回忆录"）
      └── 重要对话（importance ≥ 阈值）
```

**回忆录只从核心层取**：核心层 → 标签筛选 → 时间线锚点 → 精选 10-15 条 → 编成一条回忆录。
千条记忆 = 素材库（流水层自动清理），不是负担。

## 三、健康事件自动识别与记录（补最大空白）

### 3.1 三层触发

| 触发层 | 场景 | 实现 |
| --- | --- | --- |
| L1 对话识别 | 用户对话说症状（"它吐了""精神不好"） | 现有 agentTools 症状工具 + ingestMemories（已有） |
| **L2 打卡异常自动沉淀** | 打卡提交异常项（食欲差/拉稀/精神差） | checkins 路由调 `recordHealthMemory`（新增） |
| **L3 症状初筛自动沉淀** | 用户做症状初筛 | symptoms 路由调 `recordHealthMemory`（新增） |

### 3.2 健康事件记忆结构

```
type: health_event
content: "2026-08-22 食欲差，连续 2 天，建议观察/就医"
category: medical / health
importance: 7-9（自动按异常严重度）
evidence: 打卡记录 ID / 初筛记录 ID（可回溯）
related_photo: 可选（用户打卡上传的照片）
```

### 3.3 增强（可选）

- **连续异常提醒**：连续 2-3 天异常打卡 → AI 主动问"要不要记录详情？需要就医建议吗？"
- **康复闭环**：异常后打卡恢复正常 → 自动补一条"已恢复"记忆（时间线完整）

### 3.4 识别方式

- 规则层（0 成本）：打卡异常项白名单（食欲差/拉稀/呕吐/精神差…）+ 初筛紧急程度
- AI 层（对话）：LLM 从用户描述提取症状细节（已有 guard/症状工具基础）

## 五、数据流（回忆录如何从记忆取数）

```
记忆库（分层 + 标签 + 时间线）
  → 用户选模板（成长记/告别与怀念…）
  → 按模板标签 + importance + 时间范围 筛选记忆
  → 关联照片（记忆↔照片）
  → AI 生成剧本草稿（DeepSeek 文本）
  → 用户确认剧本
  → 生成视频
```
