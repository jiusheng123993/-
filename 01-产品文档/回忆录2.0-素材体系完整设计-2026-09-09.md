# 回忆录 2.0 · 素材体系完整设计（2026-09-09）

> 背景：Seedance 2.0 mini 实测打通生产链路后，发现素材层是"故事感"与"一致性"的真正瓶颈。
> 用户原话需求：①用户要能提供更多图片；②小程序路径要完善；③单图对应什么档位要明确；④生成完整回忆录需要提供/勾选什么要完整构造。
> 本文为唯一设计事实源，实施清单见 §八。

---

## 一、实测结论 → 设计原则（2026-09-09 验证）

| 实测事实 | 设计原则 |
| --- | --- |
| 真实照片 I2V：身份像素级一致（吊牌"福"字全程保持） | **真实照片是唯一主素材**，生图只是兜底 |
| 单图+文字锚点生图（Tier 3）：斑块形状/分布漂移，行家可见 | 生图补景必须**用户知情同意**，且只用于低信息量构图 |
| 空镜段（窗台/项圈/星空）质量稳定、氛围承载强 | 素材不足时优先**降段不降质**：删段 > 造猫 |
| 顺光+特征定位句可救毛色（草地帧第三次才达标） | AI 补景帧限制构图：远景/侧脸/睡姿，禁特写 |
| 生产 pet_moments 仅 2 条、档案相册 0 照片 | 素材引导必须前置，**进入创建页第一屏就是盘点** |

---

## 二、素材分级体系（一致性阶梯）

| Tier | 素材做法 | 一致性 | 允许的构图 |
| --- | --- | --- | --- |
| **T1 真实照片首帧**（模式 S） | 用户照片直接 I2V | 像素级（就是它本人） | 任意（照片本身决定） |
| **T2 多图参考生图** | ≥2 张真实照片作 image 数组参考 | 高（跨角度特征锁定） | 中景；脸部不超 2s 特写 |
| **T3 单图+锚点生图** | 1 张照片 + 文字锚点句 | 中（特征对、纹理漂移） | 仅远景/背影/侧脸/睡姿 |
| **P 空镜** | 无宠静物/自然景（生图或后期） | 无一致性问题 | 任意 |

**金律：宁降段，不造猫。** 缺素材的叙事节点直接跳过或用 P 段衔接，绝不默认用 T3 硬补。

---

> **2026-09-09 定稿确认（用户拍板）**：三档定价 = 轻纪念 25.9/18.9、标准 59/45、完整 99/79（非会员/会员）；会员视频类免费逻辑全部删除；生图类（头像候选/形象/全家福/AI补景）继续会员白送；2D 形象包经查证为死模块（前端无入口、生产 0 行）不定价，`generate-2d` 路由加 FEATURE_DISABLED 防误触。

## 三、档位定义（回答"单图对应什么"）

| 档位 | 素材门槛 | 成片结构 | 时长 | 定价（非会员/会员） |
| --- | --- | --- | --- | --- |
| **轻纪念**（原"日常 Vlog"并入单镜） | 1-3 张照片 | 2-3 段：真实 I2V + P 空镜 + 暖白尾 | ~20-25s | **25.9 / 18.9** |
| **标准回忆录**（新增档） | 5-7 张照片 | 6 段：真实段 + P 段衔接 | ~45s | **59 / 45** |
| **完整回忆录**（原纪念 Vlog） | 8-15 张 + 记忆勾选 ≥3 | 10 段 75 秒全流程 | ~75s | **99 / 79** |
| **AI 补景开关**（叠加项） | 任何档位可开 | T3 生图补缺失场景 | +1 段/8s | 显式勾选"与真实宠物存在差异"；默认关 |

## 四、素材需求清单（完整档）

1. **照片 8-15 张**，按叙事节点覆盖（分镜自动检测）：
   - 必需类：日常姿态 ×3（坐/卧/睡任一）、互动 ×1（与人/玩具）
   - 加分类：到家/幼年、饭盆/食物、户外、与主人同框
   - 每张都会做视觉摘要（memoirPhotoAnalysis 已上线）
2. **记忆勾选 ≥3 条**：时光线（pet_moments）真实事件 → 旁白锚定素材；一条都不勾且无自述 → 触发【无记忆约束】只写照片可见事实
3. **用户自述**（可选）：500 字内，优先级高于记忆勾选
4. **BGM**：现有 4 选 1 不变

## 五、用户路径（ memoir-vlog 5 步 → 6 步）

```
进入创建页
  └─ 第 0 屏【素材盘点】（新增，最关键）
      · 自动拉取：档案相册照片数 / 时光线记忆条数 / 历史打卡照片数
      · 给出结论："你可以生成 X 档，缺 Y，去补充 →"
      · 三条补充路径入口：拍照/相册上传 · 勾选档案与时光线照片 · 补写时光线回忆
  └─ 步骤1【选照片】= 本地上传 + 库内勾选（档案相册 / 时光线照片 / 打卡照片 三个 tab）
  └─ 步骤2【选记忆】（新增）= 时光线 moments 复选，勾选的进旁白；显示每条摘要与日期
  └─ 步骤3【写叙事】= 现有 source_text（保留）
  └─ 步骤4【选BGM】= 现有（保留）
  └─ 步骤5【确认】= 档位展示 + 素材映射预览（哪些段真实照片/空镜/AI补景）+ AI补景开关 + 支付
  └─ 生成（剧本确认闸门保留，processing 中可见分镜确认）
```

## 九、验收标准

1. 只有 1 张照片的用户：能走通"轻纪念"档，成片 100% 真实形象，无 AI 造猫；
2. 8 张照片 + 3 条记忆：走通 75 秒完整档，旁白包含勾选的真实记忆事件；
3. 素材盘点屏与库内数据一致（照片数/记忆数不虚报）；
4. AI 补景默认关闭，开启时有差异告知文案；
5. 全量测试绿 + 生产部署冒烟绿。

## 十、趣味形象模块规格（2026-09-09 双 Agent 评估 + 用户拍板）

> 创意：用户真实宠物照片 → 拟人化/穿衣图片。双 Agent（产品+技术红队）评估结论 + 7 张样例实测（`E:\星河宠记\Codex暂存\趣味形象样例\`）+ IA 原型（`E:\Codex\2026-09-09\创作板块IA原型\outputs\creative-hub-prototype.html`）。定位：**形象体系传播型 viewType + 冲动付费单品**，不做独立模块。

### 10.1 双入口（用户决断制）

| 入口 | 形态 | 实测结论 | 技术约束 |
| --- | --- | --- | --- |
| **穿戴写真**（Mode A） | 真实四脚猫穿衣服/道具 | 样例 3/3 达标，一眼认出 | 沿用换场景管线 + 服装层描述（形制/颜色/材质具体化） |
| **拟人剧场**（Mode B） | 猫头直立拟人身 | 实测 2/4——**写实微风格化+半身构图可用；全 Q 版 3D 丢品种特征** | 主题模板强制"写实微风格化+半身构图"，禁全 3D 渲染话术 |

### 10.2 定价三轨（与视频档形成 2.9→25.9→59/99 情感付费阶梯）

- 免费体验：每用户 1 次（成本 ~0.35-0.7 元，制造 wow→分享）；
- 会员：每月 4 次（成本 ~1.4-2.8 元/月，占会员月 AI 成本可控）；
- 非会员：2.9 元/3 张单品（毛利 ~64%）。

### 10.3 P0 护栏（红队钉死，缺一不上线）

1. **月度配额强制**——分钟级限流（aiGenerateLimiter 5/分）挡不住慢性薅（理论敞口 7200 张/天/号 ≈2500 元/天），月配额是唯一真成本闸；
2. **模板白名单**——首期仅预设服装模板（COSTUME_PROMPTS 8-12 套，复制全家福 SCENE_PROMPTS 模式），**绝不开放自定义 prompt**（IP 侵权面 + 重试成本双杀）；自定义后续开必须 petPrompt 清洗 + IP/品牌词黑名单；
3. **物种门禁**——生成前 `visionService.analyzeImage` 校验参考图为宠物（防用户误传人照 → 真人变装的深度合成合规风险）；
4. **真实形象门禁**——复用全家福 `MEMBER_NO_REAL_IMAGE` 同款校验，无真实照片的宠物不开放（防生成无关通用猫纯烧钱）；
5. **cosmetic 图绝不写回 pet_profiles**（avatar_photo_url/avatar_multiview_url/avatar_cartoon_url 都不碰，防污染全家福参考图链路）；
6. **AI 角标不可付费去除**（会员差异化不得是"去水印"，合规红线）；走 addAiBadge 转存本站管线。

### 10.4 架构落点

- 形象库 `view_type` 白名单加 `'costume'`（routes/avatar.ts L471 白名单 + repository 类型 + 前端筛选徽章，迁移 030 的 view_type 无 CHECK 约束，零迁移成本）；
- 服装模板 key 复用 `style` 列（如 `fun-hanfu`）；
- 双图参考分级：真实照片（管头部保真）+ multiview 设定图（管全身斑纹）> 单真实照片 > 单 multiview；`avatar_cartoon_url` 不进参考分级；
- 前端：形象定制页「趣味形象」双入口卡 + 示例图（即本批样例），形象工坊聚合页见 IA 原型（主页双入口：形象工坊/回忆录馆）。

### 10.5 排期与验证

- P1，排回忆录素材 B1-B3 之后；开发量 ~2-3 人日（viewType 白名单 + COSTUME_PROMPTS + 前端双入口 + 分享卡复用）；
- 上线卡节日节点（万圣节/春节）限定主题首发；
- 埋点闭环：share_card_open → costume_page_open → generate → pay，裂变率达标才运营化，不达标收缩为纯会员权益。
