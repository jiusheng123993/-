# 星寰海 — 软件测试路径

> 基于 PRD v4.0 设计
> 生成日期：2026-07-25
> 目的：确保不遗漏任何功能的测试

---

## 一、测试路径总览

```
测试路径分为5条主线：
路径A：用户生命周期（注册→使用→付费→留存→流失→召回）
路径B：核心功能场景（打卡→食物→症状→疫苗→趋势→报告）
路径C：家庭与社交（家庭→动态墙→排行→图谱→分享→邀请）
路径D：情绪底层（宠物离世/生病焦虑/新手焦虑/极端情绪）
路径E：安全与合规（Guard拦截/数据隐私/付费边界/P0阻断项）
```
