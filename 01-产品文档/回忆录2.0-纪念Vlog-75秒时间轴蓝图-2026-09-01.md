# 回忆录 2.0 · 纪念 Vlog 75 秒时间轴蓝图（2026-09-01）

> 目的：直观展示"1 张照片 = 1 段镜头"如何拼成一条 75 秒完整叙事视频。
> 方法论：《宠物回忆录-提示词库.md》v5.1（模式 S/C/P + 十段结构 + 五锁）。
> 实现对应：`memoirScriptService.ts`（分镜）→ `promptTemplates.ts`（十段+五锁）→ `videoGenerationService.ts`（xfade 转场 + TTS + 字幕）。

---

## 一、总览

| 项 | 值 |
| --- | --- |
| 目标时长 | 75 秒（代码目标 60-90 秒区间中值） |
| 段数 | **10 段**（8-15 段范围内；75÷8≈9.4 → 取 10 段） |
| 单段时长 | 每段 clamp 到 8 秒（Seedance 甜区 3-8 秒） |
| 分辨率 | 720p（`resolution: '720p'`，`ratio: 'adaptive'`） |
| 转场 | 段间 xfade 溶解 0.5 秒；段 6→7 用 1.0 秒长溶解 + 静音留白 |
| 旁白 | TTS（豆包 seed-tts-2.0），整条对齐时间轴；名字只出现在旁白/字幕 |
| BGM | 后期混音：0-40s 轻钢琴 → 40-56s 弦乐渐入 → 56-75s 钢琴收束；旁白时 ducking -6dB |

成本（Seedance 1.5 Pro，720p 无声）：10 段 × 8 秒 × ~0.16 元/秒 ≈ **13 元**；含整条重试中值 ~20 元。

## 三、照片选择与排序原则

1. **光线方向尽量一致**：相邻段照片光线方向相反会造成接缝跳变（SCREEN DIRECTION 锁按段独立，段间接缝靠转场吸收）。
2. **姿态决定段型**：趴/卧/坐照 → 模式 S 微动作；奔跑/跳跃照 → 模式 C 先造关键帧；无人无宠静物 → 模式 P。
3. **清晰度优先**：首帧照片的脸部/主体越清晰，IDENTITY LOCK 越稳；糊图宁换不硬用。
4. **叙事顺序**：按"时间感"排序（初见→日常→陪伴→离别→释怀），不按拍摄时间硬排。
5. **人宠同框段**：照片里必须真实有人才写人物锚点；没有就用空镜替代，不凭空造人。
