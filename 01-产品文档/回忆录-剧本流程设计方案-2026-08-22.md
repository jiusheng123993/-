# 星河宠记 · 回忆录剧本流程设计方案（2026-08-22）

> 状态：待用户审阅
> 背景：回忆录成本大头在视频生成（1.5 Pro 15-22 元/条，2.5 多宠物 125-200 元/条）。
> 核心原则：**剧本阶段花"文本钱"（DeepSeek 几分钱/次，可无限重试）；视频阶段花"生成钱"
> （几十到几百元/条）——只有用户确认剧本后才开始生成视频**，杜绝"生成完不满意返工"的浪费。

---

## 一、核心流程（确认剧本 → 才生成视频）

```
用户提交（照片 + 选剧本模板）
  ↓ ① 记忆聚合与标签化（服务端自动，0 成本）
  ↓ ② 生成剧本草稿（DeepSeek 文本：分镜脚本，~5 秒，~0.03 元）
  ↓ ③ 剧本预览（文字分镜卡片：标题/旁白/字幕/镜头描述/照片缩略）
  ↓ ④ 用户确认 ✅ ｜ 换模板 🔄 ｜ 换记忆 📝 ｜ 修改文案 ✏️
  ↓ ⑤ 确认后 → 才调 Seedance 生成视频（花大钱）
  ↓ ⑥ 质检 → 交付
```

**省钱关键**：④ 可以无限重试（每次 0.03 元文本费）；只有走到 ⑤ 才花视频钱（15-200 元）。

## 二、记忆标签体系（系统分类）

### 2.1 现有基础（可复用）

`agent_memories` 表已有：分类（medical/health/habit/preference/feeding/behavior/event/general）+ `importance`（重要度 0-1）+ `confidence`（置信度）+ `evidence`（证据链）。

### 2.2 新增"回忆标签"（情感叙事维度，叠加现有分类）

| 标签 | 含义 | 示例记忆 |
| --- | --- | --- |
| `milestone` | 成长里程碑 | 到家日、生日、疫苗、绝育、学会技能 |
| `daily_joy` | 日常趣事 | 玩逗猫棒、睡姿、搞笑瞬间 |
| `bonding` | 情感联结 | 迎接回家、依偎、分别时的不舍 |
| `special_day` | 特殊日子 | 节日、旅行、搬家、纪念日 |
| `family` | 家庭互动 | 与主人/其他宠物/孩子的互动 |
| `health_heal` | 健康时刻 | 生病被照顾、康复、手术恢复 |
| `farewell` | 告别纪念 | 已故、离世（克制处理，不渲染） |
| `seasonal` | 季节/周年 | 去年今天、四季更替、周年 |

### 2.3 打标方式（三层）

1. **规则打标**（0 成本）：关键词匹配（"生日""疫苗""第一次"→milestone 等）
2. **AI 辅助打标**（批量，0.01 元/批）：定期扫描未打标记忆 → 分类
3. **用户手动**：记忆页"标为珍贵/选入回忆录"（用户最有价值的标注）

### 2.4 记忆筛选规则（解决"记忆太长"）

- 按标签分组 → 每组按 `importance` 排序取前 N 条
- 时间线可选范围（全部 / 近 3 年 / 指定时间段）
- 照片关联：每条记忆关联的照片自动进剧本素材候选

## 三、剧本模板库（用户按标签选）

| 模板 | 适用标签 | 叙事弧 | 情感基调 | 音乐 |
| --- | --- | --- | --- | --- |
| **成长记** | milestone | 幼年→成年→现在 | 温暖、欣慰 | warm |
| **日常陪伴** | daily_joy + bonding | 日常片段集锦 | 治愈、开心 | gentle |
| **告别与怀念** | farewell | 回忆→释怀→感激 | 克制、深情 | piano |
| **家庭团圆** | family | 全家互动 | 热闹、温馨 | bright |
| **年度回顾** | seasonal | 四季→全年精选 | 感慨、展望 | nostalgic |
| **特别的一天** | special_day | 单日深度叙事 | 沉浸 | piano |

每个模板 = 叙事弧 + 镜头分布（如成长记：幼年 30% → 少年 30% → 现在 40%）+ 情感曲线 + 音乐基调。模板是分镜生成的"骨架"，AI 在骨架内填充具体记忆。

## 四、剧本生成与确认（状态机 + 接口）

### 4.1 任务状态机（扩展现有 memoir 状态）

```
pending（已提交）
  → script_generating（AI 生成剧本草稿，DeepSeek 文本）
  → script_ready（剧本待确认）← 用户在这里操作（确认/换/改）
  → script_confirmed（已确认，等待生成）
  → generating（Seedance 视频生成，花大钱）
  → completed / failed
```

### 4.2 接口设计

| 接口 | 作用 | 成本 |
| --- | --- | --- |
| `POST /api/memoir/script-draft` | 提交照片+选模板 → 生成剧本草稿 | 0.03 元 |
| `GET /api/memoir/:id/script` | 读剧本预览（文字分镜） | 0 |
| `POST /api/memoir/:id/script/confirm` | 确认剧本 → 置 script_confirmed | 0 |
| `POST /api/memoir/:id/script/regenerate` | 换模板/换记忆 → 重新生成草稿 | 0.03 元 |
| `POST /api/memoir/:id/script/edit` | 修改旁白/字幕文案（局部） | 0.03 元 |

### 4.3 生成触发（关键改动）

`memoirProcessor` 轮询：**只处理 `script_confirmed` 状态的任务**（当前是 pending 直接生成）。
- 旧任务（无剧本流程）兼容：pending 且无剧本 → 自动转 script_ready 等待确认
- 确认后 → generating → 现有 Seedance 管线

### 4.4 剧本预览内容（用户确认的界面）

每条分镜卡片显示：
- 镜头描述（照片缩略 + 运镜/景别）
- 旁白文案（可编辑）
- 字幕
- 音乐/情感提示
+ 顶部：标题 + 模板名 + **预估视频成本/价格**（透明化）

## 五、成本与体验收益

| 环节 | 成本 | 重试次数 |
| --- | --- | --- |
| 剧本生成/换模板/改文案 | 0.03 元/次 | **无限**（随便换） |
| 视频生成（确认后） | 15-200 元/条 | 1 次（不满意只能重生成，贵） |

**收益**：
1. 省钱：杜绝"生成完不满意返工"（视频返工 20-200 元/次）
2. 体验：用户参与共创（选标签→看剧本→确认），对最终视频更有期待
3. 透明：确认前显示预估价格，减少"贵"的投诉
4. 数据：用户换模板的行为 = 免费的产品反馈（哪个模板受欢迎）
