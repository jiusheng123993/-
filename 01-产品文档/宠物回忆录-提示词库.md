# 宠物回忆录 — 高端 AI 视频提示词库

> 基于全网专业提示词工程研究整理，覆盖 Seedance 2.0 / Sora / Runway Gen-3 / 可灵 Kling 四大平台。
> 所有提示词均标注适用场景与关键技术词，可直接复用或按需改写。

## 一、提示词黄金法则

### 1.1 八维黄金框架（适配所有平台）

```
[主体] + [动作] + [场景+环境] + [光影] + [镜头语言+运镜] + [风格+情绪] + [音频/物理] + [时长/转场]
```

### 1.2 核心法则

| 法则 | 说明 |
|------|------|
| **前20-30词权重最高** | 必须把"谁/什么"放最前面，风格氛围往后放 |
| **甜区50-120词** | 太长后半段会被忽略 |
| **不写negative prompt** | Seedance 2.0不支持，反而干扰 |
| **具体>模糊** | 不写"beautiful"，写"Terrence Malick style, golden hour" |
| **情感动作>静止描述** | 写"tear rolling"而非"she is sad" |
| **分镜叙事** | 用"Shot 1 / Shot 2 / quick cut to / Return to"切分 |
| **角色一致性必加** | `using character @角色名 consistently` + 每镜头重复`@image` |

### 1.3 五维架构法（进阶）

1. **技术基底**：8K UHD、HDR10+、48fps、色彩空间
2. **运镜基底**：slow dolly in / tracking shot / panning / crane up / circling 360
3. **物理基底**：realistic physics, natural motion, accurate weight/momentum
4. **光影基底**：golden hour / volumetric fog / rim light / god rays
5. **风格基底**：cinematic teal/orange / kodak portra / Terrence Malick style

## 三、角色一致性技术（Seedance 2.0 专属）

### 3.1 黄金三段式

**第一步：参考图准备**
- 角色三视图最佳（正面、侧面、3/4角度）
- 高清、无遮挡、光线均匀
- 仅正面照可用，但跨角度一致性下降

**第二步：核心锁定提示词模板**

```
character lock: [年龄] [性别]，[发型]，[五官特征]，[肤色]，[服装]
@image [上传角色参考图]
face keep: 全程保持面部特征一致，无变形、无崩坏，表情自然，细节清晰
shot setting: 镜头衔接自然，无断层，保持场景统一，光影连贯
```

**第三步：多镜头叙事（每个镜头开头都要重复@image）**

```
镜头1（全景）：@image [同一参考图]，[角色描述]，[场景]，[动作]，[光影]，[质量约束]

### 3.3 通用角色一致性写法

```

### 3.4 已知局限

- 极端角度（仰拍、俯拍）仍可能轻微崩坏

- 无法跨视频角色一致——每次生成独立
- 参考图质量直接决定锁定效果

## 八、避坑清单

| 错误 | 正确 |
|------|------|
| 写 negative prompt | 用正向描述约束 |
| 一次堆5个运镜 | 每次只加1个运镜 |
| 堆砌术语无结构 | 按"镜头→主体→光影→参数"顺序写 |
| 写"beautiful"模糊词 | 写"Terrence Malick style, golden hour" |
| 提示词过长（>120词） | 控制在50-120词甜区 |
| 写"一个女孩"模糊主体 | 写"25-year-old Asian woman, long black hair, red hoodie" |
| 忽略风格一致性 | 每个分镜开头重复`@image`与角色描述 |
| 全程固定镜头 | 推近→环绕→拉远组合 |
| 通篇痛感无出口 | 痛感后必有释怀（天堂/风/光） |
| 全程一种BGM情绪 | 三段式情绪曲线 |
