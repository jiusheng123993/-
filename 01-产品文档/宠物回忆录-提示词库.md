## 零、提示词工程方法论

### 0.1 Seedance 2.0 通用公式（核心）

```
[主体] + [动作] + [镜头运动] + [场景+光影+天气] + [风格/导演参考] + [物理真实感] + [音频描述] + [时长]
```

**模板骨架**：
```
A [详细主体描述] is [具体动作], [镜头运动], in [场景+光影+天气], [风格/导演参考], realistic physics, natural motion, synced to [音频描述], [X] seconds seamless.
```

### 0.2 五大黄金法则

| 法则 | 说明 | 示例 |
|------|------|------|
| **前20词决定80%质量** | 主体+动作放最前面 | 先写"Golden retriever running"，后写风格 |
| **甜区50-120词** | 太短缺乏细节，太长后半段被忽略 | 控制在中等长度 |
| **具体 > 模糊** | 写品牌/风格名代替形容词 | 写"Kodak Portra 400"而非"vintage" |
| **动作描述 > 情绪标签** | 写"tear rolling down cheek"而非"sad" | AI理解动作比情绪更准 |
| **一个镜头一个运镜** | 每次只加1个核心运镜词 | 不要同时写dolly+pan+tilt |

### 0.3 Seedance 2.0 @标签系统（角色一致性核心）

```
@Image1 [上传宠物参考图正面]
@Image2 [上传宠物参考图侧面]
@Image3 [上传宠物参考图3/4角度]

Prompt中引用：
@Image1 的毛色和体型保持一致，自然运动，无面部变形
```

#### 0.3.1 多角度参考包升级版（2026-08 最新做法，全平台通用）

> 来源：MiniMax H3 Omni Reference 官方指南 / invideo 多角度角色卡教程（2026-07）/ lxe/skythread R2V 实战（2026-08-05）。

每个角色先做一套多角度参考包，一次做好、反复用：

```text
正面肖像 → 锁脸、发型、年龄、身份
3/4 侧面 → 锁面部立体度
全身照   → 锁服装、鞋、体型比例、道具
面部特写 → 锁五官细节（可选）
```

规则：
- 生成之间不换参考图，否则等于没锁。
- 同一套图不能自相矛盾（图1短发、图2长发会被模型平均化）。
- 多角色时，脸最正的图放最前，提示词按 `<Picture 1>`、`<Picture 2>` 顺序引用。
- 每张图只分配一个职责，用 "only / do not copy" 防串扰：
  `Image 1 锁脸，Image 2 锁服装，Image 3 只锁场景光线，不得迁移任何面部或服装特征。`
- 场景单独做"空镜参考卡"，只锁环境/光线，不锁人物。

### 0.5 MiniMax H3 提示词结构（新增）

#### I2VA（图生视频，首帧/参考图锁定）

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

integrated_multimodal_description:
[镜头1] 0-5秒,<事件+运镜+角色锁定+光线色彩>。……画面中只有<在场人物>。

overall_soundscape:
<环境声、动作音、台词，按层写清触发点>

non_diegetic_music:
<音乐风格、进入点、情绪>

负面约束:禁止出现……
```

#### R2V（参考驱动，多图锁角色 · 官方六段式）

```text
subject_definitions: 定义被引用内容与标签(<Subject 1> / <Picture N> / <Video N> / <Audio N>)
summary: 任务类型、目标视频、主要引用关系
retention_analysis: 引用内容如何保留/迁移/复用
detailed_description: 按播放顺序写画面、动作、镜头、声音、对白
overall_soundscape: 环境声与物理音效
non_diegetic_music: 背景音乐
```

本地部署说明：ComfyUI 的 `MiniMaxH3ReferenceToVideo` 节点，`ref_images` 支持最多 9 张
参考图（另有参考视频/音频）；R2V 使用独立权重 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`
（约 19.5G，与 I2V 的 fl2va 权重不通用）。参考图按连接顺序用 `<Picture 1>` 引用。

### 0.6 全局角色锁定表（必建，先于一切提示词）

```markdown
## 全局角色锁定表（每幕必须遵守）
- 角色A：身份+年龄+五官+发型+体型+服装+配饰+道具，写死。允许变化：表情、视线、姿势、呼吸。
- 数量敏感角色（如"外婆"）：显式声明"全片只能出现这一个"。
- 易跑偏角色（如"猎人"）：显式排除兽化特征"绝对的人类，没有兽耳/獠牙/尾巴/毛皮，不是狼人"。

## 每幕声明
- 在场人物：<写死>
- 禁止人物：<写死，防模型加戏>
```

宠物回忆录实例：

```text
- 宠物：成年金毛，金黄色卷毛，胸口白色斑块，戴红色皮质项圈+铜铃铛。全片同一只，毛色体型不变。
- 主人：35岁东亚女性，齐肩黑发，米色针织开衫，浅蓝牛仔裤。全片同一人。
- 禁止：第二只宠物、宠物变种/换毛色、主人换人、画面文字、水印。
```

### 0.7 负面约束清单（H3 适用；Seedance 用正向表达）

```text
禁止出现：第二个<角色>、角色身份互换、角色融合、多手多脚/畸形肢体、
狼人/半兽人/兽耳人类、多余路人、数量不符、画面文字/字幕乱码、水印、
镜头抖动、硬切、浮空部件。
```

注意：Seedance 2.0 不支持负面提示词（见第八节避坑表），该平台继续用正向写法；
H3 在 prompt 内直接写"禁止出现……"有效，且几乎每条高质量 H3 提示词都带负面约束。

### 0.8 跨模型一致性：配方卡 + 回归测试

同提示词在不同模型上结果必然不同（提示词不可移植），靠 5 层兜住：

1. 提示词只写"模型无关"的控制点：客观可验证描述（金色晨光丁达尔光、暮色蓝调、低机位缓慢推近），少用"电影感/高级感"空词。
2. 参考图优先：角色参考包锁身份，提示词只管动作。
3. 固定配方：模型文件+LoRA+采样器+步数+seed+分辨率+帧数，每次记录配方卡。
4. 换模型前回归测试：同一参考图+锁定提示词，新旧模型各出一段逐项对比（角色/数量/运镜）。
5. 视觉校验兜底：DeepSeek 多模态逐张检查"角色构成、数量、有无畸形"，不过就重生成。

配方卡模板（随交付文档保存）：

```markdown
## 生成配方卡
- 模型：minimax_h3_ref2va_pruned_int8_convrot.safetensors + turbo LoRA(1.0)
- 参数：8步，864×480，124帧(5秒)，seed=xxx
- 参考图：<文件名>（职责：锁脸/锁服装/锁场景）
- 提示词：见对应分镜
```

### 0.9 细节描写清单（眼神/身体动作/逐秒拆解）

> 用户要求："提示词要每一个细节都描写,具体到眼神、身体动作。"
> 写每幕详细描述时,对每个在场角色逐项过一遍,并按秒拆解(0-1s/1-2s/2-3s/3-4s/4-5s)。

**眼神与面部**：眼神方向（看路/看镜头/看对方）、眼睛状态（睁大/眯起/半闭/瞳孔变化/第几秒眨眼）、
视线追踪（瞳孔跟随某物）、眉毛（扬起/紧锁）、嘴（微张/抿紧/嘴角/吞咽）。

**身体与动作**：重心转移（哪只脚承重）、停步/后退时哪只脚先动、手部（握道具/抬到胸口/攥拳/指节）、
肩背（绷紧/放松）、呼吸（吸气胸腔起伏/急促/松气）、头部偏转角度。

**衣物与道具**：衣摆/斗篷/发辫被风吹动方向、道具（篮子/花/斧头）位置与拿法。

### 0.10 Seedance 2.5 十段 Prompt Contract（2026-08 新增，代码已实现）

> 依据：OpenMontage `seedance-2-5` 技能（GitHub 最新版）+ 星河宠记 `promptTemplates.ts` 实现。
> 顺序不能乱：跳段不会整体变差，但会在"可预见的特定方式"上坏掉。

```
GLOBAL STYLE（全局护栏：类型/调色/画幅/必须不出现的东西）
SCENE（一句话剧情线）
CHARACTERS（角色=参考图+本镜在场锚点逐字重复）
LOCATION（位置与道具，防多镜漂移）
FIRST FRAME（开场构图 x/y 百分比）
Shot 1/2/3（镜头分解 + 动作）
OPTICS（焦段锁定）
PHYSICS（毛发/布料等柔软细节）
LIGHTING（单一光源方案）
AUDIO（环境声；无音乐）
```

**Prompt 形状**：顶部一条视觉规则 + 中间镜头分解 + 底部一条声音规则。

### 0.11 Locks 连续性锁（跨镜头一致性，代码已实现）

| Lock | 作用 | 示例 |
| --- | --- | --- |
| COUNT LOCK | 数量锁定 | "画面只出现照片中已有的宠物与人，不出现额外动物/人物/镜面倒影第二个" |
| SCREEN DIRECTION | 方向轴 | "主体始终朝向画面右侧，永不反转" |
| IDENTITY LOCK | 合规护栏 | "无 logo、无可读文字、无字幕、无水印" |
| STILLNESS LOCK | 不发生的事 | "猫保持趴卧不动，只有耳朵/尾巴微动" |
| State monotonicity | 状态只前进 | "光线只会更暗不会恢复" |

### 0.12 多角色锚点（多宠物/多人，2026-08 新增，代码已实现）

> 4 猫 2 人家庭场景：每个在场角色一个锚点，全片逐镜逐字重复。
> 人物用稳定特征（发型/服装/体型），不用表情；每镜只声明本镜在场角色（characters_present）。

```jsonc
"anchors": [
  { "id": "doubao", "type": "pet", "desc": "橘色短毛猫，白色胸脯，右耳缺一角" },
  { "id": "mama", "type": "human", "desc": "女性，长发，米色毛衣" }
],
"segments": [{
  "characters_present": ["doubao"],   // 本镜只有猫在场
  "seedance_prompt": "……CHARACTERS 段只注入 doubao 锚点……"
}]
```


**逐秒模板**：

```text
[镜头N] 0-5s,<景别>。
0-1s: <角色A>眼神/手/身体在做什么; <角色B>……
1-2s: <状态变化,触发动作>
2-3s: <关键动作,表情转折>
3-4s: <眼神/手部细节>
4-5s: <收束落点,镜头动作>
```

每段写"谁+眼睛/手/身体+做什么",避免只有情绪词；音频也按触发秒数写。

**角色全貌锁定（从头发到脚趾）**：每个角色写一段完整外观,按顺序:
头发(颜色/编法/发饰)→额头→眉毛→眼睛(颜色/形状/睫毛)→鼻子→嘴→下巴→脸颊→
耳朵→脖子→领口→上衣(领型/扣子/口袋/袖长)→腰身→裙/裤→手(指形/饰品)→腿→
鞋(靴筒/鞋带/鞋头)→随身道具。写进 subject_definitions 或独立的
character_appearance_lock 段,每幕对在场角色重复注入,并加"形象与参考图完全
一致,不得改变任何外观细节"。

## 八、避坑清单

| 错误写法 | 正确写法 | 原因 |
|----------|----------|------|
| `beautiful, amazing, stunning` | `Terrence Malick style, golden hour, 8k ultra detailed` | 模糊形容词AI无法理解 |
| `she is very sad` | `tear rolling down cheek, trembling lip, slow motion 60fps` | 用动作描述代替情绪标签 |
| `a girl` | `25-year-old Asian woman, long black hair, cream sweater` | 主体必须具体描述 |
| 一次写5个运镜 | 每次只写1个核心运镜 | 多运镜会让AI混乱 |
| 提示词超过150词 | 控制在50-120词 | 后半段权重极低 |
| `not ugly, not blurry` | `sharp focus, clear details` | Seedance不支持negative prompt |
| 写中文提示词 | 写英文提示词 | Seedance 2.0英文理解优于中文 |
| 忘记@image约束 | 每个镜头开头加@image | 否则角色会变脸 |
| 通篇悲伤无出口 | 悲伤后必有释怀场景 | 用户体验需要情绪释放 |
| 角色没写死（猎人变狼人） | 全局角色锁定表 + 每幕"在场/禁止人物" | 身份、数量、兽化特征必须显式排除 |
| 参考图职责不清 | 每张参考图只分配一个职责 + "only / do not copy" | 多图混用会导致特征串扰 |
| 换模型后角色漂移 | 配方卡 + 一致性回归测试 | 同提示词≠同结果，模型间不可移植 |
