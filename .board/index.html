💡 决策记录
症状初筛采用规则引擎而非AI对话
原因：规则引擎可控、可审计、零AI成本，避免AI幻觉风险（R001/R003）
情绪能力隐形化策略
原因：避免被认定为心理咨询（R002），情绪能力不出现在功能列表中
宠物形象使用Seedream API
原因：0.3元/只成本可控，会员免费/非会员付费，状态表情用SVG叠加0成本
保守策略：宁可误报不可漏报
原因：症状初筛误判延误就医是P0风险（R003），误报成本远低于漏报
旧代码全部删除而非保留兼容
原因：旧方向与PRD v3.1架构不兼容，保留会增加维护成本和混淆风险
