# GrowthOS 微信小程序（独立工程）

这是 GrowthOS 个人成长系统的微信小程序原生工程，**可直接用微信开发者工具导入**，无需安装任何依赖，与桌面端 React 项目物理隔离。

## 使用方法

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择本仓库下的 `mini-program-app/` 文件夹（不要选仓库根目录）。
4. AppID 选择「测试号」或填写自己的小程序 AppID。
5. 项目名称可自定义，默认 `growthos-miniprogram`。
6. 点击「确定」即可在模拟器中预览。

## 与桌面端的关系

- 仓库根目录的 `miniprogram/` 是桌面端 React 项目内嵌的小程序蓝图镜像，被 Vitest 单元测试与桌面端预览引用。
- 本目录 `mini-program-app/` 是独立工程，结构、页面源码与 `miniprogram/` 完全一致，通过测试保证同步。
- 修改任意一边的页面文件后，必须同步更新另一边并跑 `npm test` 校验一致性。

## 页面清单

| 路径 | TabBar | 说明 |
| --- | --- | --- |
| pages/home/index | 首页 | 今日优先级、快捷入口、低压力恢复、复盘提醒 |
| pages/plan/index | 计划 | 任务、目标、日程时间盒、轻量复盘 |
| pages/quick-add/index | + | 快速记录任务、灵感、症状、笔记、错题、临时想法 |
| pages/modules/index | 模块 | 模块开关、隐私级别、可用 / 预留状态 |
| pages/profile/index | 我的 | 隐私控制、本地导出、删除数据二次确认、设置入口 |

## 隐私与同步

- 高敏感数据（症状、情绪、私人笔记）默认仅本地保存。
- 同步、导出、删除等操作均预留接口，第一版不强制上线真实云同步。
- 删除数据必须经过二次确认。
