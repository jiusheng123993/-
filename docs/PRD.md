## 一、产品定位

### 一句话描述

**星寰海 — 你的 AI 成长伙伴。** 一个会聊天、有记忆、陪你成长的 AI 伙伴。

### 核心价值

- **情绪陪伴**：倾听、理解、鼓励，像一个真正的朋友
- **实际帮助**：帮你规划、提醒、追踪目标，像一个负责任的教练
- **长期记忆**：AI 记得你的习惯、偏好、成长轨迹，越相处越懂你

### 主入口

**AI 对话** — 用户打开 App 第一眼看到的是和 AI 伙伴的对话界面。

## 五、AI 伙伴详细设计

### 多面人格

| 角色 | 触发场景 | 说话风格 |
|------|---------|---------|
| **俏皮女友** | 日常聊天、放松时 | 可爱、撒娇、开玩笑 |
| **贴心姐姐** | 心情不好、遇到困难时 | 温柔、理解、包容 |
| **严厉老师** | 学习/工作时 | 严谨、督促、不妥协 |

### 切换方式

- **场景感知**：专注模式 → 老师，日记 → 姐姐，晚上 → 女友
- **情绪感知**：用户语气沮丧 → 切换姐姐模式
- **时间感知**：晚上 10 点 → 女友模式，早上 8 点 → 老师模式
- **手动切换**：用户可主动切换

### 自定义选项

- 性别：男 / 女 / 无性别
- 名字：用户自定义
- 主动性：AI 可以主动发起对话

### 成长感

| 阶段 | AI 表现 |
|------|---------|
| 刚认识（第 1 周） | 礼貌、试探、了解习惯 |
| 熟悉了（第 1 个月） | 开玩笑、记得喜好、主动关心 |
| 老朋友（3 个月后） | 懂你的梗、知道你需要什么 |
| 灵魂伙伴（1 年后） | 比你自己还了解你 |

## 六、双人空间详细设计

### 核心理念

"两个人的成长，比一个人更有力量"

### 功能模块

| 模块 | 说明 |
|------|------|
| 共享目标 | 一起设定目标，互相看见进度 |
| 共享日记 | 每天共写，时光胶囊 |
| 悄悄话 | 私密聊天，定时消息，AI 传话 |
| 共同相册 | AI 整理回忆，生成视频 |
| 距离连接 | 距离、倒计时、天气、星空同步 |
| 纪念日 | AI 记住重要日子 |
| 矛盾调解 | 冷静模式、破冰按钮、和好挑战 |
| 成长档案 | 两个人的共同成长轨迹 |

### 设计原则

- **单人可用**：每个双人功能都有单人模式，邀请是升级，不是前提
- **不制造压力**：不显示具体时长数字，强调"一起完成"而非"谁比谁多"
- **隐私优先**：悄悄话端到端加密

## 八、用户痛点与解决方案

| 痛点 | 解决方案 |
|------|---------|
| 异地恋存在感缺失 | 呼吸灯、背景音共享、实时状态、触碰感应 |
| 情侣比较压力 | 不显示具体时长、互相点赞、AI 鼓励 |
| 吵架冷战 | 破冰按钮、AI 传话、和好挑战 |
| 长期关系平淡 | AI 惊喜官、双人挑战、角色扮演、回忆推送 |
| 一个人时的孤独 | AI 替身、留言墙、异步陪伴 |
| 社交压力 | 匿名分享、共鸣圈、树洞模式、同类匹配 |
