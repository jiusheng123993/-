# 个人学习规划记录桌面应用设计

## 产品定位

面向年轻人和学生党的桌面端个人学习规划与记录应用，强调高级校园风视觉、游戏化成长激励、可扩展主题系统、本地数据保存和未来云同步能力。

## 第一版范围

第一版提供首页仪表盘、学习目标、计划任务、每日打卡、番茄专注、学习笔记、错题复习、基础统计、成长等级和主题中心。云同步、主题市场、AI 学习建议、OCR 错题识别作为后续扩展点预留。

## 技术方案

当前环境没有 Rust 和 Cargo，因此第一版采用 Electron + React + TypeScript + Vite，确保桌面应用可以落地运行。若后续安装 Rust 环境，可在保持 React UI 与业务模块的基础上迁移到 Tauri。

## 架构分层

- 表现层：React 页面、卡片、导航、主题中心和仪表盘。
- 业务数据层：学习目标、任务、笔记、复习项、成长状态和用户偏好。
- 扩展层：主题注册表、本地数据 Provider、未来云同步 Provider、备份导出 Provider。

## 主题系统

内置高级校园、游戏成长、梦幻紫粉和夜间专注四套主题。每套主题提供颜色、背景、渐变、图表颜色、圆角、阴影和玻璃效果 token。后续新增主题只需新增主题配置并注册，不改学习业务模块。

## 数据保存

第一版使用浏览器 localStorage 作为本地保存基础，Provider 接口隔离存储实现。后续可替换为 Electron 文件存储、SQLite 或云同步 Provider。

## 测试策略

使用 Vitest 和 Testing Library。测试覆盖主题注册表、数据 Provider 初始状态和读写契约、主界面渲染和主题切换行为。
