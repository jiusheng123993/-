# Persona 选择界面重构设计文档

## 1. 背景与问题

当前 Persona 选择界面通过四个大按钮（打工人、学习党等）让用户选择身份，这种方式不符合用户主动选择场景的逻辑。用户应该能够自由描述自己的需求，而不是被动选择预设身份。

## 2. 设计目标

- 让用户主动选择使用场景，而非被动选择预设身份
- 支持自由编辑和自定义
- 实现差异化服务，不同身份对应不同功能模块
- 完全重新设计主界面，采用侧边栏 + 可拖拽画布布局
- 动画效果全面对齐鸿蒙系统

## 3. 身份系统（Identity System）

### 3.1 选择方式
- **自由描述**：用户可以用自然语言描述自己的身份和需求
- **标签组合**：提供常用标签供用户快速选择（学生、打工人、宝妈、创作者等）
- **AI 推荐**：根据用户描述，AI 推荐默认模块组合

### 3.2 数据隔离策略
- **核心数据共享**：任务、笔记、专注记录等基础数据全身份共享
- **模块配置隔离**：每个身份有独立的模块配置和布局
- **主题偏好隔离**：每个身份可独立设置主题

### 3.3 切换方式
- **手动切换**：通过侧边栏的身份切换入口
- **快捷切换**：支持快捷键或手势快速切换最近使用的身份
- **场景自动切换**：根据时间或行为模式智能推荐切换

## 4. 模块系统（Module Store）

### 4.1 模块商店模式
- **推荐模块**：AI 根据身份推荐默认模块
- **分类浏览**：按场景分类（学习、办公、生活、健康等）
- **搜索功能**：支持关键词搜索模块

### 4.2 模块管理
- **添加模块**：从模块商店添加
- **删除模块**：长按进入编辑模式后删除
- **创建自定义模块**：用户可创建空白模块并自定义内容
- **自定义模块内容**：编辑模块内的数据和展示方式
- **调整模块顺序**：拖拽调整

### 4.3 默认模块
- 今日任务
- 专注计时
- 日历
- 笔记
- 天气
- 自定义模块按钮
- 数据统计

## 5. 主界面布局

### 5.1 整体结构
- **侧边栏**（可隐藏/收起）：包含身份切换、模块商店、AI 助手、设置、主题切换
- **可拖拽画布**：网格布局，用户可自由调整模块位置

### 5.2 卡片设计（鸿蒙风格）
- **外观**：圆角矩形、阴影、无边框、毛玻璃效果
- **大小**：小(1x1)、中(2x1)、大(2x2)、全宽(1x2)
- **交互**：
  - 单击：展开卡片详情
  - 长按：进入拖拽模式
  - 双击：进入编辑模式
  - 滑动：删除卡片
  - 捏合：缩放画布

### 5.3 智能对齐
- 拖拽时自动吸附网格
- 显示对齐参考线
- 支持自由摆放和网格吸附两种模式

## 6. 动画效果（鸿蒙系统风格）

### 6.1 卡片动画
- **入场动画**：从下方滑入，带弹性效果
- **hover 效果**：轻微上浮 + 阴影加深
- **点击反馈**：缩放 + 阴影变化
- **拖拽状态**：半透明 + 阴影增强

### 6.2 过渡动画
- **页面切换**：共享元素过渡
- **卡片展开**：从原位置平滑展开
- **侧边栏展开**：滑入 + 背景模糊渐变

### 6.3 动画参数
- **缓动函数**：cubic-bezier(0.4, 0, 0.2, 1)（鸿蒙标准）
- **时长**：
  - 快速反馈：150ms
  - 标准过渡：300ms
  - 复杂动画：500ms
- **性能**：使用 transform 和 opacity，避免触发重排

## 7. 侧边栏设计

### 7.1 默认状态
- 隐藏，只显示边缘触发区域

### 7.2 内容
- 身份切换
- 模块商店
- AI 助手
- 设置
- 主题切换
- 布局锁定/解锁

### 7.3 展开方式
- 点击边缘按钮
- 快捷键（如 Cmd/Ctrl + B）
- 边缘滑动（桌面端鼠标悬停）

## 8. 布局管理

### 8.1 保存
- 自动保存布局变化
- 支持手动保存为预设布局

### 8.2 分享
- 链接分享
- 应用内分享

### 8.3 导入
- 链接导入
- 应用内导入

### 8.4 锁定
- 锁定后禁止编辑和拖拽
- 解锁后可自由编辑
- 锁定按钮在侧边栏底部

## 9. AI 助手

### 9.1 形象
- 人物角色、动物宠物、幻想生物、简约图标
- 全部可自定义

### 9.2 交互方式
- 独立 AI 聊天窗口
- 模块内助手
- 全屏视频通话
- 悬浮小助手

### 9.3 功能
- 自然语言交互
- 数据分析
- 智能推荐
- 内容生成
- 规划建议

## 10. 通知设计

### 10.1 Toast 通知
- 位置：居中显示
- 时长：2 秒
- 动画：缩放 + 淡入淡出
- 缓动：ease-in-out
- 主题：跟随当前主题

## 11. 技术实现

### 11.1 关键技术
- React 18 + TypeScript
- 拖拽库：@dnd-kit 或 react-beautiful-dnd
- 动画：Framer Motion 或 CSS Transitions
- 状态管理：React Context + useReducer

### 11.2 文件结构
```
src/
  identity/
    IdentityProvider.tsx       # 身份上下文
    useIdentity.ts             # 身份 Hook
    identityStore.ts           # 身份存储
    types.ts                   # 身份类型定义
  module-store/
    ModuleStore.tsx            # 模块商店组件
    ModuleRegistry.ts          # 模块注册表
    useModuleStore.ts          # 模块商店 Hook
  canvas/
    DraggableCanvas.tsx        # 可拖拽画布
    CanvasCard.tsx             # 画布卡片
    useCanvasLayout.ts         # 布局管理 Hook
  sidebar/
    Sidebar.tsx                # 侧边栏
    SidebarToggle.tsx          # 侧边栏切换
  animations/
    harmonyOS.ts               # 鸿蒙动画配置
    useHarmonyAnimation.ts     # 动画 Hook
```

5. 侧边栏实现
6. 布局管理（保存/分享/导入）
7. AI 助手集成
8. 动画优化
