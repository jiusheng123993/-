## 一、产品定位与愿景

### 1.1 一句话定位

**星寰海** = 个人学习规划记录 + AI 智能体陪伴 + 游戏化成长激励 + 关系互联协作

面向年轻人（18-30 岁）的桌面端 + Web + 小程序三端学习生活管理工具，强调高级校园风视觉、游戏化成长激励、AI 智能体深度陪伴。

### 1.2 核心差异化

| 维度 | 竞品现状 | 星寰海差异化 |
|------|---------|-------------|
| AI 能力 | 多数竞品仅提供简单 AI 建议 | **有记忆的 AI 搭子**：长期记忆系统 + 行为观察 + 自我进化 |
| 视觉体验 | 功能型 UI，缺乏个性 | **高级校园风 + 多主题系统**：4 套内置主题 + 可扩展 |
| 游戏化 | 简单积分/等级 | **角色进化 + 成就徽章 + 关系 PK**：3D 角色随行为进化 |
| 关系协作 | 多数为单人工具 | **关系空间**：情侣/家庭/搭子多人协作 + 实时 PK |
| 数据主权 | 云端强制 | **本地优先 + 可选云同步**：隐私敏感数据本地加密 |

### 1.3 目标用户画像

| 用户类型 | 核心需求 | 付费意愿 |
|---------|---------|---------|
| 大学生（考研/考公） | 学习规划、番茄专注、错题复习 | 中（学习会员） |
| 职场新人 | 习惯养成、目标管理、时间记录 | 中高（学习会员） |
| 自律爱好者 | 打卡、统计、成长可视化 | 高（Agent 会员） |
| 情侣/搭子 | 共同目标、互相监督、关系成长 | 高（关系互联） |
| AI 爱好者 | AI 陪伴、角色养成、个性化 | 高（Agent PLUS） |

### 5.3 关键技术决策

| 决策点 | 推荐方案 | 理由 |
|--------|---------|------|
| 后端语言 | Node.js (NestJS) 或 Go | 团队熟悉度决定；Go 性能更好，Node.js 与前端技术栈统一 |
| 数据库 | PostgreSQL | 关系型数据为主，JSONB 支持灵活字段 |
| 小程序框架 | Taro | React 语法，与现有代码复用度高 |
| 3D 渲染 | Three.js | 生态成熟，文档丰富 |
| 实时通信 | WebSocket (Socket.io) | 关系空间实时 PK 需要 |
| 云存储 | 阿里云 OSS / 腾讯云 COS | 壁纸、3D 模型等文件存储 |
| 部署 | Docker + 阿里云/腾讯云 | 国内用户访问速度优先 |

## 七、风险与应对

### 7.1 技术风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 云同步数据一致性 | 高 | 冲突检测 + 最后写入胜出 + 版本向量 |
| 3D 渲染性能 | 中 | 降级为 2D + 模型复杂度限制 |
| AI API 不稳定 | 中 | 多供应商备选 + 预设角色库兜底 |
| 小程序审核 | 中 | 提前了解审核规范 + 预留审核时间 |

### 7.2 商业风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 付费转化率低 | 高 | 免费功能足够好 → 自然转化 + 限时优惠 |
| 竞品跟进 | 中 | 持续迭代差异化功能 + 用户数据沉淀壁垒 |
| 用户流失 | 中 | 长期记忆系统增加迁移成本 + 关系空间增加社交粘性 |

### 7.3 合规风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 用户隐私（周期数据等） | 高 | 本地优先 + 加密存储 + 隐私锁 |
| 未成年人保护 | 高 | 年龄验证 + 关系空间功能限制 |
| AI 生成内容合规 | 中 | 内容审核 + 敏感词过滤 |
| 支付合规 | 中 | 持牌支付机构 + 用户协议 + 隐私政策 |
