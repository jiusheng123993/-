# 专注模式 - 设计文档

## 概述

全屏沉浸式专注空间，集成番茄钟、自定义任务、多种背景主题和白噪音，帮助用户进入深度专注状态。

## 设计风格

柔和高端 (Soft) - 优雅、沉浸、细腻的视觉体验

## 功能清单

### 核心功能
1. 开始/暂停/重置番茄钟
2. 圆形进度环（SVG 环形进度条）
3. 树生长动画（专注时生长，完成时开花，放弃时枯萎）
4. 番茄计数（今日完成数）
5. 今日累计专注时长
6. 目标设置（自定义专注时长）
7. 休息提醒（番茄钟结束后自动切换休息模式）
8. 勿扰模式（隐藏通知）
9. 空格键控制（开始/暂停）
10. 夜间模式（暗色主题适配）
11. 记住上次任务
12. 声音提醒（完成时播放提示音）
13. 休息建议（休息时展示拉伸/喝水建议）
14. 放弃记录（放弃时记录原因）
15. 一键分享（分享专注成果）
16. 震动提醒（移动端适配）
17. 自定义休息时长
18. 历史记录入口
19. 完成动画（撒花/粒子效果）

### 任务管理
20. 自定义任务（创建、选择、切换）
21. 任务列表管理

### 背景主题（18种）
22. 森林、海洋、夜空、天空、落叶、樱花、沙漠、雪山、日出、日落、草原、星空、雨后、城市、山脉、湖泊、花田、极简

### 背景音乐（23种）
23. 自然白噪音：雨声、雷雨、海浪、溪流、森林、风声、壁炉、蝉鸣夏夜
24. 氛围场景：咖啡馆、图书馆、火车旅途、城市雨夜、太空舱、深海
25. 纯音频率：白噪音、粉红噪音、棕色噪音、432Hz纯音（Web Audio API 生成）
26. 器乐轻音：钢琴轻音、吉他指弹、大提琴、氛围电子
27. 关闭音乐

### 自定义背景
28. 上传自定义图片/视频作为背景
29. 管理已上传背景（预览、切换、删除）

## 技术架构

### 文件结构
```
src/focus-mode/
├── FocusModeUI.tsx          # 主组件
├── focusModeService.ts      # 数据服务（任务、记录、设置）
├── focusMode.css            # 样式（含18种背景主题）
├── backgroundThemes.ts      # 背景主题配置
├── audioManager.ts          # 音频管理（Web Audio API + 音频文件播放）
├── treeAnimation.ts         # 树生长动画逻辑
└── types.ts                 # 类型定义
```

### 数据存储
- localStorage：任务列表、番茄记录、用户设置
- IndexedDB：自定义背景图片/视频

### 音频方案
- 纯音频率（白噪音/粉红噪音/棕色噪音/432Hz）：Web Audio API 实时生成
- 自然声/器乐：用户提供的 mp3 文件，存放于 public/audio/
